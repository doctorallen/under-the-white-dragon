# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

Under the White Dragon (it grew out of Downlevel, a detective game whose mechanics are gone now) is a side-scrolling cyberpunk game for the phone browser, held sideways, in plain JavaScript: no build step, no dependencies, no modules. It's a game about fixing things in a vertical city: you live in a hidden basement under the White Dragon, a noodle bar (`d_dragon.js`: the street, the bar, the storeroom and its trapdoor, and the basement `d_cellar`, where new games start; it's `hidden`, so not on the city map), take jobs to your bench (`bench.js`), use parts with a grade and a history (`parts.js`), strip machines for salvage and parts, sell to the stalls, take cabs about the city, and watch your heat (`jobs.js`); its design is in the doc linked from `DESIGN.md`. There's no fighting, no health, no gear and no detective work: the touch controls are a stick, Use and Jump, and the city's people are residents with lives (`town.js`, run by Tyrell through `city.js`). The city runs in bands from the sky down (`STRATA` in `worldmap.js`): up high, street level, the undercity, Old Town, the Works and the Bowels, each opening once you've been in the one above (`Travel.open`). The dev tools show only with `?dev`. Read `README.md` for the file map and controls, `js/tuning.js` for every number, `js/items.js` for the salvage you carry, `js/parts.js` for parts and devices, and `DESIGN.md` for the design. Sections of `DESIGN.md` marked **(proposed)** aren't built yet. Ask before building on them in a way that's hard to undo.

## Commands

```sh
git submodule update --init     # Tycho, the engine, with Tyrell, the minds engine, in vendor/tycho (needed to run)
python3 -m http.server 8000     # play at http://localhost:8000
npm install                     # test tools only (puppeteer-core)
npm test                        # everything CI runs: test/check.sh, test/golden.js, test/traces.js, test/gpu.js, test/sound.js, then test/smoke.js
node test/golden.js --update    # re-record the golden values after a change to the levels, painting, sprites or frames that's meant
node test/traces.js --record    # re-record the runner's traces, only after a change to how it moves that's meant
node test/sound.js --wav        # every place's music and every effect as .wav previews in test/out, to listen to
node test/city.js 3             # the city for three days: what's said on screen, what passes between residents, a day's CPU (not in npm test)
git -C vendor/tycho pull origin main    # take a newer Tycho (then run the tests and commit the pointer)
```

The tests run on Tycho's test kit (`vendor/tycho/dist/testkit.cjs`): Playwright's Chromium, or puppeteer-core with the Chrome in `$CHROME`, as CI does. `test/golden.js` pins every level's shape and painting, the sprites and a few frames (`test/golden.json`); a change that moves them must be meant, re-recorded, and said in the commit. `test/traces.js` replays the runner's movement recorded from the code before it moved onto Tycho (`test/traces.json`: walls, every pace, jumps and hops, stairs, walkways up through and down through, coyote jumps, ladders, falls, and seeded random input) and holds every frame's position and state to it bit for bit; how the runner moves must not change unless that's meant, and then the traces are recorded again and the commit says so.

## Architecture

- **Globals and load order.** Every file is a classic script in one global scope, loaded in order by `index.html` (`util.js` first, `main.js` last). A new file needs its `<script>` tag (`test/check.sh` fails on one missing, and on duplicate top-level names); the service worker keeps whatever `index.html` names.
- **Installable, never stale.** `manifest.webmanifest` and `sw.js` make it a PWA. `sw.js` is a few lines that import Tycho's worker (`vendor/tycho/dist/tycho-sw.js`), which goes to the network first for everything (revalidating past the HTTP cache), uses its cache only offline, and keeps what `index.html` names plus `files` (the font). The deploy stamps `__BUILD__` in `sw.js` and `js/pwa.js` (`PAGE_BUILD`) with the commit and writes `version.json`, so every deploy is a new worker; `js/pwa.js` runs Tycho's installable app (`Tycho.pwa`), which checks for one whenever the game returns to the foreground and every 15 minutes, and when it takes over, saves and reloads, unless the page is already that build (a fresh launch after a deploy loads the new code from the network, so it mustn't reload again). Don't make the worker cache-first.
- **Levels are code.** Each level (in the `d_*.js` files; what they share is in `levels.js`) is built once through the builder in `world.js` (`newLevel`): painting operations (`L.paint`, `L.block`, `L.sign`, `L.tube`…), solid boxes (`L.solid`, `L.wall`, `L.floor`), one-way surfaces (`L.walk` walkways, `L.stairs`, stood on from above only), ladders, props, lights and people (`L.npc`, with a daily schedule). `World.load(id)` makes it the current level, with its shape as a Tycho collision space (`L.space`, `World.space`: the solids, the props that block until they're done, the sides, the walkways, stairs and ladders), which `World.hits`, `World.way` and `World.ladderAt` ask. A save keeps only what changed: props done by id (`Game.s.done`), flags, what you carry (`pack`), the parts and notebook, the bench, jobs, heat, tips, the time, and the residents' minds (`save.js`, on Tycho's save store, `Tycho.save.Store`: localStorage `whitedragon.save.v1`, save version 1; `Save.start` deletes Downlevel's old save, `downlevel.save.v1`, puts renamed ids right, `Save.RENAMED`, drops what an older save kept that nothing reads now, `Game.OLD`, and starts over from any save of another version).
- **Seeded.** Painting and sprites use `hash` and `Rng` only, never `Math.random` (enforced by `check.sh`), so the city always paints the same.
- **Painting.** `paint.js` paints the level lazily in chunks (`T.chunk` px square) on Tycho's painter (`Tycho.paint`, `vendor/tycho/docs/paint.md`, which grew from this file): the pixel buffer `Pix` (`put`, `tint`, `area`, `block`) and the chunk cache `Paint` (`reset`, `get`, `ahead`) are Tycho's; the materials (`MAT`) and the city's own painters (windows, signs, pipes, railings, laundry, slabs, water...) are here, on top. A chunk runs only the operations whose box touches it; each operation gets its own seed (`op.seed`), so strokes meet across chunk edges without seams. Painting is flat (`PAINT_FLAT` in `paint.js`, passed to Tycho's buffer as `flat`): each surface one tone from its value, a crisp lit top edge and shaded bottom (Tycho's `blockV`), panel lines, drips, no noise and no brushwork. (Set it false and the old way comes back: short strokes of close tones, Tycho's `strokeRow`, and beveled lips.) Behind it a level can have parallax layers (`L.layers`, back to front, each painted once and moved at its fraction `f` of the camera's speed); `skyline.js` paints their towers (`tower`, `skylineLayer`, `cloudBands`) and draws what moves on them each frame: giant holograms (`L.holos`) and the monorail train (`L.train`). A chunk is a color canvas plus a glow canvas.
- **Rendering** (`render.js`). The view is small (`T.view.min` px on the short side) and scaled up by whole device pixels: the frame is finished at `View.out` screen pixels per view pixel (at most 3, lower when `Perf` in `main.js` sees frames under 40 a second, or as the dev setting says) and CSS scales the canvas the rest of the way, pixelated. Where there's WebGL2 the whole frame is drawn on the GPU by Tycho's renderer (`vendor/tycho/docs/renderer.md`): `View.gpu` is the batcher, and `View.lg` (the picture) and `View.gg` (what glows) are its stand-ins for 2D contexts, so the drawing code is written as for a 2D canvas and must keep to what the stand-in takes (fillRect, drawImage, alpha, the blend modes, save/restore, translate/scale/rotate, a rect clip, a linear gradient). A canvas drawn from is copied to the GPU's atlas once, so one that's painted again after it's been drawn needs `View.gpu.dirty(canvas)`. Without WebGL2, or with `?nogl` in the address, the same calls run on 2D canvases (`View.low`, `View.gl`) and the game finishes them in 2D; `test/gpu.js` draws the same frame both ways and holds the lit picture and the glow to a few tones, and the golden frames are the 2D path's. Order: far layer, chunks (each erasing the far layer's glow behind it), props, then the light: the light map (`lightMap`, a 4 px grid fixed to the world) scaled up smooth and multiplied over all of it, with a tenth of it added (on the GPU, Tycho's smooth light pass, `View.light`; each light adds itself only over the cells it reaches). Keep it smooth: hard light cells read as a grid over the screen. People are lit after that, each by the light where they stand with a floor (`lightAt`), so figures always read: on the GPU a tint on the quad (`g.tint`), in 2D a tinted copy cached on the sprite by quantized color (`s.lit`); don't go back to compositing through a shared scratch canvas per figure, which stalls the GPU. Then the parts of props in front of people (`p.front`, multiplied by the light map pixel by pixel: `g.lightMap` on the GPU) and rain. Day and night are `day.js` (`Day`, numbers in `DAY`): in places open to the sky (`L.open`, from `district`'s `sky`) the light map's ambient goes toward a gray overcast by day (rose at dawn, amber at dusk), a haze goes over the city behind (and the flight's) and the neon's bloom dims; interiors and the undercity keep their own light. It's driven by the clock alone. The finish (`finishFrame`; on the GPU Tycho's blur finish, `View.post`): the glow halved by averaging and blurred into two bloom layers (averaging keeps the bloom steady as the camera moves), then picture + glow + bloom, reflections (`L.wet`: water always; a street's, marked `rain`, only as wet as `Weather.wet()` says) and the fade, scaled up to the screen. The weather is `Weather` in `day.js` (`WEATHER`): rain comes and goes in spells worked out from the day's number, drizzle to downpour (`Weather.rain()`, which scales the rain drawn and the splashes, and puts up umbrellas), and the ground dries after; places under a roof or glass (`rain: 0`) get none. Dev can force it. The smoke test plays the phone run on the GPU and the desktop run in 2D.
- **Sprites** are painted from shapes (`Spr` in `spr.js`: `ell`, `box`, `cap`, `shape`, `limb`, `poly`) and cached. The painter is Tycho's (`Tycho.sprite.Shapes`, `vendor/tycho/docs/sprite.md`, which grew from this game's), as are `canvasOf` (`Tycho.sprite.canvas`) and `flipSprite`; the looks (the ramps, `person`, the props) are this game's. Every sprite is flat pixel art by default, props and figures alike (`Spr.soft` gives the old soft-run shading if something needs it): three hard tones a material and no noise, a box a flat panel (lit top and left edge, shaded bottom and right), a shadow line where a later part (`S.part()`) lies over an earlier one (`S.part(false)` for one that casts none, like hair on a face), and a dark outline, with the details (eyes, a coat's opening and buttons, a buckle, seams and rivets) placed by hand. Keep everything flat: no soft volume shading, no bevels or embossing. People come from `person(o)` in `people.js` (hair, coat, chrome, what they hold, a pose), side-on, or from behind with `view: 'back'` (`personBack`: the runner on a ladder). The runner is a tinker in safety-orange coveralls with a chrome forearm lit blue (`RUNNER` in `player.js`, drawn by `RunnerArt`), wearing tinker gear any figure can wear: a tool belt, a satchel, goggles pushed up, gloves, rolled sleeves (and a loupe, a headlamp, a cable coil, a beanie, tools out of a pack). Sprites carry anchors `ax`/`ay` at the feet.
- **Play.** `player.js` moves the runner against the level (Tycho's platform mover, `Tycho.move.Platform`, as `RUNNER_MOVER`, with `T.player`'s numbers and `T.pace`: the stick's pace (a walk, a run and a sprint at double the run, by how far it's pushed; the keys run, Shift sprints, C walks: `T.stick`), coyote time, the short hop, ledges stepped up, stairs followed, dropping through walkways, ladders; `vendor/tycho/docs/world.md`) and works Use (`Player.interact`: the nearest prop or person; stripping is held). The controls are Tycho's (`Tycho.input.Controls`, `vendor/tycho/docs/play.md`): `input.js` keeps the names the game reads, refreshed each step by `Input.apply()` (the axes `Input.ax`/`ay`, what's held `jump`/`use`, and the presses waiting, `useHit`/`jumpHit`, each read once by `Input.take`), and draws the stick; the maps' drag and pinch are Tycho's gestures (`Tycho.input.Gestures`), the wheel the game's own. Props' kinds, looks and uses are in `things.js`. People are in `actors.js`. `life.js` is the city's ambient life: light flicker (`L.sign`/`L.tube`/`L.fire` lights carry a `flick` mode), adverts (`L.ad`), flying traffic on the far layer (`L.traffic`), critters (`L.critter`), litter (`L.litter`), smoke and steam (`L.vents`), drips (`L.drips`); it's all driven by the clock and `hash`, so none of it is saved (the puffs and splashes age and run out by Tycho's `Tycho.fx.age`, `vendor/tycho/docs/fx.md`). Nobody is put down to wander: everyone you see is a resident (below). Anyone a builder calls "Commuter" or "Fruit seller" (`PARTS`) still gets a name of their own as the level is built (`personName`, from the level and where they stand, the same every visit), the part kept as their `title`; the census turns them into the post or spot they stood for. `Game` (`game.js`) has the rules: what you carry (salvage, no limit) and payment, the clock, and moving between levels (`Game.go`). Stripping shows what came out a line each, rising over the machine (`Game.gain`, drawn by `Hud.tick`, placed by `Tycho.fx.rise`).
- **Places and travel.** Every place is built by hand. `kit.js` holds the pieces (buildings `bShophouse`, `bCapsules`, `bMachiya`, `bTemple`, `bPagoda`, `bGlass`, `bStack`, `bDanchi`, `bTheater`, `bBath`, `bArcade`, `bPark`; painters `kRoof`, `kLattice`, `kNoren`, `kLantern`, `kAwning`, `kBalcony`, `kWin`, `kShop`, `kTree`, `kTorii`...; stalls `kStallAt`) and `district(o)`, the frame a place is built in (ground, the city behind or a ceiling, the way in, crowd, light), with `addDistrict` to register it, and `arena` for a great hall at a street's end. The places are in `d_high.js`, `d_street.js`, `d_under.js`, `d_old.js`, `d_works.js`, `d_deep.js`; each file's own helpers carry its prefix (`hi`, `st`, `un`, `ot`, `wk`, `dp`). From the ground the camera shows about G-155 to G, so keep the detail that matters low. Build to the people's scale (an adult is 33 px): a door 40 px high, a story about 50, a window about 18 × 22 (`KS` in `kit.js`). Every level has `meters` (its depth) and `mapX`; `worldmap.js` pins them on the city map, which is how you travel, and `Travel` (`travel.js`) decides what's open (where you've been: a band opens once you've been in the one above, `BAND_ABOVE`) and how you get there (cab, manhole, subway, cage elevator). The city layers behind sky places are painted once and shared (`World.shared`).
- **The tutorial.** A new game (`Tutorial.begin`, from `boot`) starts with Lin's radio on the bench (`JOBS.lin`, a job you take back to her yourself, `self`) and the coil it needs on the shelf; `tutorial.js` walks it: `TUT` is the steps, each done when the game says so (`done()`), so being ahead just moves it on (the step machine is Tycho's guide, `Tycho.guide.Guide`, `Tutorial.G`; what it says and shows is the game's). It shows as a card under money and heat (`#guide`), a box beside the bench's tools with the place to touch marked (`Tutorial.mark`, `tutMark`), and a line at the top of a panel with its button pulsing (`Tutorial.decorate`, `.tut`). Then Ozzy's nav unit: stripping (`flags.stripped`), the market, buying, selling salvage (`flags.sold`), home. Its place is `Game.s.tut`; a save without one never sees it.
- **The basement.** `Bench` (`bench.js`) is a panel with its own canvas (`BW` × `BH` bench pixels, drawn flat and scaled up) and a side of HTML it redraws alone (`Bench.side`); what's on the bench is saved (`Game.s.bench`), the tools' state in hand isn't. Devices and parts are data in `parts.js` (`DEVICE`, `PART`, `GRADE`, `PART_STOCK`); parts you have are instances in `Game.s.parts` (things of their own on `Tycho.items.things`, their ids from `Game.s.pid`), the notebook is `Game.s.notes`. `Jobs` (`jobs.js`) puts its customers into the White Dragon (`Jobs.spawn`, from `Actors.spawns`), has its work offered, haggled over and handed back in talk (below; `Jobs.actionsFor` says what someone has for you, `Jobs.haggle` how far they'd go on the pay, `Jobs.html` the cards when there's no talk), has finished work collected (`Jobs.collections`, from `City.sync`: whoever waits at the counter takes it a quarter hour after it's tested; a resident gets a Tyrell directive to `collect` at the noodle bar, rank 1.6, above free time and below work, its hours keeping them from coming in the night; they pay on collection), keeps heat (`Game.s.heat`) and writes the morning after when you sleep (`Jobs.morning`). Residents also bring small paid repairs, two a day (`Jobs.oddToday`, `ODD`; a scrap part fitted in one may give out overnight, and that resident stays away a few days, `sour:` flags), and tips: `Tips` (`tips.js`) sends a message in the morning or has them tell you (`TIPS`, `Game.s.tips`), and `World.tipProps` puts the machine in its level; it strips only with a good enough kit (`Game.s.tools`, `TOOLS`, `STRIP_TIER`; `TIP_YIELD` in `parts.js`).
- **The city's people: the census and the folk.** `census.js` (`Census.take`, at start) builds every level and reads it into places: the streets (each with its band, ground, row and way out), rooms (a hidden level behind a street's door, with spots inside by act, from `TOWN_PLACE`), doors with nothing drawn behind them (homes from the kit's buildings, `L.home`; shops from every shopfront, `kShop` with `SHOP_AMEN`; schools, the Mercy, depots, the hotel, laundries, baths, offices, `L.amenity`), and spots in the open (stall counters, park benches, temple steps, play, `L.hangout`). The people a level was built with become posts (a job with shifts, `POST_KIND`/`POST_SHIFTS`: the first shift keeps their name and look, the rest wear the uniform) or spots where residents do what they were doing (`POST_SPOT`: the audience, the patients); the passers-by are dropped. Secured places (the server farm) have only their staff's posts, so only staff go there. `folk.js` (`Folk.make`) then makes about 320 people in households (singles in capsules and shacks, couples and families in apartments and houses, retired couples, a few living alone) to fill every shift, housed near their work (the deep's jobs go to people from street level and Old Town, who ride down); children go to their part of the city's school on weekdays and play nearby after; everyone has a hobby or two (`likes`). They all join `RESIDENTS` (the block's own, written by hand, keep their days), and doors know who lives behind them (`Census.doorText`, `Census.mapLabel`), saying so once you know them (below, Knowing people).
- **The residents' minds: Tyrell.** The city's residents are run by Tyrell, a minds engine that lives in Tycho's repository (github.com/doctorallen/tycho, pulled in as a git submodule at `vendor/tycho`); `index.html` loads the built `vendor/tycho/dist/tyrell.js` (one global, `Tyrell`) and the bridge, `tycho-minds.js` (`Tycho.minds`: the glue a game with people on Tyrell needs, the clock, the save, seats, presence, travel times, witnesses and reports; `vendor/tycho/docs/minds.md`), before everything else, `sw.js` caches it, `check.sh` fails if it's missing, and the deploy checks out submodules and copies the built scripts the page loads. Its docs are in `vendor/tycho/tyrell/docs/` (start with `README.md`; `for-ai.md` is written for agents). `city.js` is the White Dragon's shell for it (`City`): it declares the needs (hunger, energy, fun, company, chores), the places (every census place, tagged `do:<act>` for what's done there, with slots for its seats and its hours), the actions (`CITY_FREE`: eating, drinking, pachinko, the pictures, dancing, the bath, the temple, the park, play, errands, each at the nearest places tagged for it and weighed by the person's hobbies and the walk; work, school and errands only where they're done), and every resident. The block's own days (`Town.plans`) become routines; everyone else's are made from their lives (`City.routineOf`: a shift, set out in time to get there, sleep fitted round it, the family home after; school and play for children, weekdays only; free time for needs and hobbies). Travel times come from `Town.route` (on foot along a band's row of streets, or a ride by cab, manhole, subway or lift when that's quicker or the only way, `TOWN_RIDE`) at the residents' pace (`PXH`), so arrivals agree on screen and off. Tyrell decides where everyone is; `City.state(id)` turns that into `Town.state`'s shape (a route walked by progress, or a spot by activity via `Town.spot`, with seats handed out so nobody sits in anybody, `City.seat`), and `Town.sync` only works that out for people who might be in your level (`City.mayBeIn`). A new city runs five hours before you see it; Esper keeps a day of snapshots, thinning with age. The game's clock drives Tyrell's (`City.sync`, from `Town.sync`: minutes = (day × 24 + time) × 60), forward and, through Esper's time walk, back (further back than it remembers, the block starts over). The player is a person to them: talking to someone (`City.did('talked')`), a repair (`fixed`, `botched` from `Jobs`) go in their file on you; stripping someone's machine in front of residents is sensed (`City.strip`, from `things.js`; who saw is `City.witnesses`: a whole room indoors, shouting distance on the street), they believe it, gossip it, and may report it (heat, `CITY.reportHeat`), and whoever saw speaks up there and then (`Chat.react`, its words `CHAT_REACT` as Cityspeak lines: whoever works there first, then a couple of others a beat apart, some residents in their own words); `City.remark` gives their lines about it, `City.morning` what's going round. Their minds are saved in `Game.s.city` (`City.stash` from `Save.write`; `City.init` after `Save.start`). The dev drawer (Map and dev, below) reads anyone's mind, walks the clock back, goes to someone, and opens Tyrell mode (`tyrellmode.js`, `TyrellMode`, the `tyrell` panel, on Tycho's minds inspector, `Tycho.inspect`: `vendor/tycho/docs/inspect.md`; the mind, the clock and the panel's wiring are Tycho's, the map and the words for places and people the game's): the whole city drawn from the minds, every street a line band by band with people on it, indoors under their door or between streets, or one street or room as its painted picture with people on it and counts of who's behind each door; pick anyone for their mind (doing what till when, needs, today's routine, the last decision with every option weighed and what ruled the rest out, the chronicle, who they know), and run the clock from there (play at a speed, step back and forward; back is Esper's time walk). In dev Tyrell keeps a longer log and more decisions (`City.make`).
- **Between residents: Bree.** What passes between residents is Tyrell's Bree (`chat.js`, `Chat`; its docs are `vendor/tycho/tyrell/docs/modules/bree.md`), on screen and off, saved and rewound with the minds. Two residents somewhere together (Tyrell's meetings: one starts something where the other's doing something) strike up a word now and then, and on and off while they stay (`CITY_BREE`, Bree's settings in `City.make`, tuned with `test/city.js` to talk on screen about as much as the old chatter did: `strike`, `again`, the turns by how they stand, the beat between turns, `quiet` for sleep and school); in a room you can see, only within a few stools (`City.beside`, `CHAT.beside`, from where each is drawn, their own spot rather than the seat handed out). Small talk (`chat`) runs topic by topic, each a pair of Cityspeak lines (`<topic>.open`, `.reply`, and a curt answer when the turn lands sour or worse, `CHAT_SOUR`): `TOWN_SMALL` (the rain one only while it rains: `fact:raining`, `City.check`, the weather by the minds' clock), a pair's own (`TOWN_PAIR`, the first of the two raising it) and the news once your work's out in the street (`TOWN_NEWS`, each on a fact the game keeps in the world, `Chat.keepFacts` from `City.sync`). Small talk meets no need (given `relieves`, chats at home kept people from the bars, the bath and the park, and the city's days changed). How each turn lands is by their natures (`City.nature`, the `nat` term: temper, warmth, patience, forgiveness from who they are, some of the block's own their own, `CITY_NATURE`), moods, needs and regard: talk warms them to each other, a sour turn can become an argument (`argue`; no fights, the block quarrels with words), arguments leave grudges that fade, keep people apart (Bree's avoidance in their choices) and are made up (`apologize`, `make_up`) or shown (`avoid`); whoever sees a row (or talk turning into one, `seenAt`) remembers it, feels it and thinks less of whoever started it, but doesn't take it as news to pass on (`witnessStrength: 0`: gossip of every row in a city this size piled up beliefs for months) (`City.onlookers`, Bree's witnesses: a room or a door, everyone there awake; a spot in the open, the spots within `CITY.reach`). Arriving at the till, a bar's or an eatery's counter or a neighbor's door begins its own two lines with whoever's serving or in (`interact` and `interactWith` on the pay, drink, eat and visit actions: `till`, its topics `CHAT_TILL`; `order`; `visit`). On screen each turn goes up over the speaker's head as it's said (`Chat.turn`, from `bree:turn`; not while the city's catching up on hours slept), a beat after their own last words (`Chat.say`, `CHAT.beat`, its queue run by `Chat.tick`). Greetings in passing and a word between two walking together stay barks (`Town.chatter`): Tyrell doesn't know who passes whom, so they change nothing, but their words are lines too (`passing`, `passing.back`: none from someone with a grudge; `Chat.small` draws a topic of the settled talk). Tyrell mode's mind shows who someone's talking with and their worst grudge (`Chat.about`). Without Tyrell, the old chatter: the same words, by the clock.
- **The block and its people.** The White Dragon's street (`d_dragon`) has doors (`door` props) into hidden interiors, and each interior has its way out drawn on its back wall where you come in, often mid-room (`innerDoor` in `props.js`, `look` noren/glass/steel; `TOWN_PLACE.inside` matches it): the noodle bar (`d_noodles`, in `d_dragon.js`), Mo's grocery and the apartments (`d_block.js`). Neon Row's places are in `d_neon.js` (`NR_DOORS`, `nrRoom`; the izakaya, the pet shop, the pachinko hall, the cinema, the Coil with its hours, the shrine), and the businesses' machines in them (tills, dryers, a jukebox, pachinko machines, a cash machine...) strip for heat (`OWNED` in `things.js`, `OWNED_YIELD` in `parts.js`; more if anyone's watching). Residents walk between streets too (off one street's end and on at the next's, `TOWN_GAP` hours off screen a street, or by the way out of the band), and staff stand behind counters and audiences sit in the seats (`TOWN_PLACE`'s `depth`, `bCounter`, `seatRow`). Walking off the end of any district takes you to the next one at the same depth (`Travel.neighbors`, `Travel.edge`; spawns `west`/`east`); spinner pads are cab stands (a fare, free once Ozzy owes you). The block's own residents (`RESIDENTS` in `town.js`) each have a home, a job, friends and a day plan; `Town.init` expands errands, finds each place in the census (`Town.resolve`: a room, `at:<level>@<x>`, `@` a door's name, `near:` a tag) and spaces the plan, `Town.state(id, hour)` gives where someone is from the clock alone (a route out of one door, along the street, in another, up the stairs), `Town.sync` keeps the ones in your level among `Actors.npcs` (`def.town`, moved by Town, not by `sched`), and `Town.chatter`/`arrived` do greetings in passing, a word walking together and what's said to Lin over the counter (the rest of their talk is Bree's, above); `Town.talk` (Use on one of them) opens the grocery's till for the clerk, a trade for someone on shift at one (those panels have a Talk button), and a talk for anyone else. Without Tyrell, `Town.clockState` places the block's own from the clock alone and nobody else is about; with it, they're all Tyrell's (above). On shift at a post with a trade (a stall that buys, a parts counter), a resident trades (`R.job.role`, `stock`).
- **Talk.** Talking to someone is a conversation on Tyrell's Voice (`talk.js`, `Talk`; Voice's docs are `vendor/tycho/tyrell/docs/modules/voice.md`). Use on a resident, on Lin or on a customer at her counter opens the talk panel (`PANELS.talk`, drawn by `Talk.panel`), docked on the right with the two of you framed on the left (`Talk.frame`; full width on a narrow screen, `TALK_NARROW`): their face (`Talk.portrait`, their figure from the front) and name, then the thread so far (`Talk.log`, added to by `Talk.record` as each answer's done: their bubbles on the left, yours on the right with how it came at them and how it landed, what you learned, a job's card when it's new or changed), the newest of it said aloud at a talking pace by Tycho's typer (`Tycho.ui.Typer`, from `Talk.after`; your own words at once, a tap on the thread hurries it, and the answers wait till it's done), then the answers as the usual chunky buttons, one to a line, each tagged with how it comes at them (`TALK_APPROACH`: straight, warm, joke, ask, haggle, bluff, bribe; each lands well or badly by the listener's traits, mood, needs and regard for you, and a strong landing moves their regard), then their trade's button (Lin's Eat), Let it lie and Goodbye (their last word goes up over their head). They raise what's theirs first (Voice's `theirs`, always: `theirs: 1` in `City.make`): what they saw you strip (`saw`: deny it, own up or pay them off, `TALK_BRIBE`; believed, taken well or paid, they keep quiet, their belief silenced so they neither report nor gossip it; not, heat through `Jobs.heat` and their regard), what they heard (`heard`), then business: a job (`job`: take it, ask what's wrong, haggle the pay up to `Jobs.haggle`'s limit, turn it down; `job.again` raises it later), the hand-back (`back`), a lead (`tip`, which `Tips.tell`s it), how what you fixed is holding (`fixed`). A resident with nothing of that to raise opens on what they're at (Voice's `opens`: the `at.*` threads, on shift, at their fun, on an errand, on their way, by `talkMoment`, kept in `Talk.context`): their greeting comes with answers to it, which lead into the subject they touch (doors, `thread:<id>`). Then you pick from a few subjects, those about what was just said first (every thread's `about`: work, fun, home, day, street, job; Voice's `followPull`, `T.talk.follow`, and `reshuffle`), then freshest: the job you're on for them (`wait`, with its checklist), their work, what they do for fun, who's at home, what's next in their day, what's going round, the block's own their story (`TALK_ABOUT`), and Lin's, Ozzy's and Vey's own. What the threads read of the game's state (the jobs, a lead due, your money) is kept in the world before each talk (`game:talk`, `Talk.context`) so that Esper replays a talk the same, and what a talk does to the game comes out as `talk:do` events (silent on a replay), carried out once the answer's done (`Talk.flush`: `Jobs.take` at the agreed pay, `Jobs.handBack(id, false, true)`, `Tips.tell`, `Jobs.heat`, paying). The answers that take or hand back a job carry `data-job` (`take:<id>`, `back:<id>`), which the tutorial pulses. The words are Cityspeak lines where they're the moment's (`TALK_LINES`: goodbyes, closings, reactions, the beats' words, the most specific for the speaker and the moment) and the game's own data where they're that (`TALK_WORDS`, by key: the greeting is `Town.talkLine(n, true)`, what they're about; the offer is `JOBS`' or `ODD`'s; a lead is `TIPS`'), with `{pay}`, `{more}`, `{mid}` filled in. Lin, Ozzy and Vey aren't residents: they join Tyrell's world the first time they're talked to (`TALK_STORY`, `Talk.ensure`), each in a place of their own doing an action of their own (`own`), so they never touch the city's days. The talks are in the minds' save (`City.stash`). A talk ends when its panel closes (`Hud.toggle` calls `Talk.close`). What residents say to each other is Bree's (above), not Voice's; the two share Cityspeak's lines, so a topic of the residents' mustn't be one Voice says (`greet`, `bye`, `close`, `react.*`, the beats' keys). Without Tyrell the old panel (their line, `Jobs.html`'s cards) and the old Use (Lin's noodles at once, a line in a bubble, a lead told) are still there.
- **Knowing people** (`known.js`, `Known`; Voice's [Knowing someone](vendor/tycho/tyrell/docs/modules/voice.md#knowing-someone)). What a talk teaches you (`learn('work'|'likes'|'home'|'about')`, the note `TALK_NOTE`) Voice keeps in the pair's bond, and familiarity is half a point a talk and a point a thing learned; the numbers are `T.known` in `tuning.js`. Once learned, the generic subject gives way to one that recalls it (`work.again`, `likes.again`, `home.again`, with `recalls`: "How's the sweeping?", their children by name, `talkAskWork`/`talkAskHome`/`TALK_ASK_LIKES`), and answers recall it too (`{learned.home:kids}`, the haggle that knows what their work pays); Voice fills the words through `voice.remembered` (`talkRemembered`), and a recall lands `recallLand` better (✎ on the button and in the thread). Old Wen's work is a duty, not a job (`TALK_DUTY`, `talkWork`). Familiarity is trust: every answer lands better (`familiarLand`), a witness is slower to report you (Wormtongue's `familiarReport`), `Jobs.haggle` goes higher (`Known.haggleUp`), and their trade's prices are better for you (`Known.rate` for what a stall pays for salvage, `Known.price` for parts at a stall or the grocery's till, `Known.deal` the line saying so). Known well (`T.known.favor`), a resident raises a favor once (the `favor` thread, `theirs`; `Known.favorFor`, kept in `Talk.context` and carried out by `Talk.flush` into `Game.s.favors`): a friend's price if they trade, a lead only they know of (`TIPS` with `friend`, never a morning message), or else a job of theirs (`Jobs.favorJob`, an odd job's id with `:favor` on the end). The notebook's People page (`Known.html`, the pack's People tab and a button on the shelf) lists `voice.acquaintances()`: their face (`Talk.face`), what you remember in the game's words (`talkWorkNote`, `talkHomeNote`), how well you know each other (`Known.band`) and how they stand with you, favors and what they saw, and the work you've done for them, open first then newest (`Known.jobsOf`: JOBS and the odd jobs, how each came out and paid, `c.paid`, `c.out`, `c.died`; an open one's checklist, `Jobs.needs`, folded away). Doors name who lives there only once you've talked to one of them or learned who's at home (`Known.door`, from `Census.doorText` and `mapLabel`; without the minds, as before). `Known.people()` is cached until a talk (`Known.dirty`), a reload or a rewind.
- **Sound** (`sound.js`, `music.js`), made in code on Tycho's engine (`Tycho.audio`, `vendor/tycho/docs/audio.md`): nothing is loaded. `snd(name, opts)` plays a cue (`SND_CUES`, the recipes; with `x`, `y` it's quieter further from the runner and panned), never throws, and is silent before the first tap. `Snd` is the engine (the mix is `T.sound`, read live; its own stream `SND_RAND`, never the game's), ticked from `loop()` paused or not. `Music` (`music.js`) is the score: a pad and a bass (Tycho's drones) moved through `MUS_PROGS` two bars a chord, the arpeggio, the beats and the phrases scheduled an eighth at a time a little ahead (`T.sound.ahead`), all by the place's mood (`MUS_MOODS`: by `MUS_PLACE`, else the band, `MUS_BAND`), heard through a radio's speaker or a wall where the mood says; the White Dragon's is Lin's radio, static until `JOBS.lin` comes back working. Each place's own sound (`MUS_BEDS`, `MUS_EVENTS`), the rain and what's near (tubes, vents, fires) are on the effects' bus, so music off leaves the city heard. `Music.listen` hears the game every frame for what it doesn't call itself: footsteps (by `Player.walked`, the poses' strides, and what's underfoot), jumps, landings, rungs, the cutter (`Player.hold`), the bench's driver and iron (`Bench.hold`), a talk's words while `Talk.typer` types, a line over a head (`n.bubble.seq`), and money in and out. Sound only reads the game. The settings (music, sound: on, soft, off) are `SndSet`, in localStorage `whitedragon.sound`, apart from the save. `test/sound.js` renders every cue and mood offline and plays the game to hear it; `--wav` writes previews to `test/out`.
- **Flying.** `flight.js`: a flight is its own mode; while `Flight.on`, `step` runs only the flight and `render` draws it (its own painted copy of `cityLayers`) before the usual finish (`finishFrame`), then `Game.arrive`.
- **Toasts, rising lines, buttons.** News is a toast or two at the top (`Game.toast`) and what Use just got rises over where it came from (`Game.gain`), on Tycho's interface kit (`Tycho.ui`, `vendor/tycho/docs/ui.md`): `Hud.toaster` (two at most, on the game's clock) and `Hud.rising`, drawn by `Hud.tick`. A panel's buttons are wired by their data attributes (`panelBind`, `Tycho.ui.bind`).
- **Map and dev.** `map.js` paints every chunk of the level into one picture (cached per level) for the pause map. `dev.js` is the dev tools, on Tycho's dev drawer (`Dev.drawer`, a `Tycho.dev.Drawer`: `vendor/tycho/docs/dev.md`), shown only with `?dev` (or once it has been): docked at the right while the game runs on behind it, opened with the ` key, the Dev button (`#bDev`) or Dev in the pause menu. Its tabs: Mind (the picked resident's mind, `Tycho.inspect.mind` with its dense options, live: tap someone on screen, `Dev.pick`, or pick from a list), Events (Tyrell's log as events in Westmarch's own words, `describe`, sorted into kinds by `DEV_LOG`, `Dev.logEvents`, with the game's own notes, hooked onto `City.strip` and `Jobs.take`, `handBack` and `heat` by `Dev.hook` so those files needn't know it; by kind, the many walks, doings, bonds and small talk left out of all), World (the clock, the weather, the city's counts as Tyrell mode counts them, this level and who's in it, you, the frame) and Tools (the switches; run speed and time of day as steppers, never sliders; the weather and resolution; give; the world; Tyrell mode's city map; Go to someone, `Dev.peopleHtml`, landing beside them through `Dev.landAt` in `Game.arrive`; Go to a place, by band, each street with its rooms, `Dev.goHtml`). Its overlays (names and what they're doing over heads, the collision boxes, what Use reaches, the census's spots and doors, the painted chunks) are drawn each frame on its canvas over the game (`Dev.overlays`, from the loop, which reports the frame's times to it). The testing switches are in localStorage `downlevel.dev` with the drawer's own state (speed in `Player`, the clock in `step`, the weather in `Weather`, the resolution in `View`); while one that changes play is off its default (`DEV_PLAY`) a tag says so on screen. A panel opened with the drawer open makes room for it (`--dev-right`), and the camera keeps the runner in the middle of what's left (`Dev.shift`).
- **Time.** `step(dt)` (`main.js`) is one fixed 1/60 s step. Panels set `Game.paused`.

## The look of the menus

Menus and the HUD are a game's, not a web page's: Dragon Pixel (`fonts/dragon.woff`, our own font, built by `python3 tools/mkfont.py fonts/dragon.woff` from the glyphs in that script; add a glyph there if text needs one) at 15px for text and 20px for titles and buttons; windows and cards with cut corners (`--cut`, `--cut-s` in `css/style.css`) over the dimmed game; chunky buttons (`.go` the main one). The skin is the last section of `css/style.css`. Anything a job needs is shown as a checklist with the part's picture (`Jobs.needs`, `Parts.icon`, `Parts.sources`). The parts you have are counted, not listed: a card a kind, a row a grade and gauge, a chip a state (`Parts.stock`, `Parts.stockHtml`; on the bench, one choice for each alike, `Parts.choices`; counted by `Tycho.items.group`, the words and HTML the game's), and never where they came from.

## Testing changes

`node test/smoke.js` plays through the slice headlessly on a phone and a desktop: it steps the game with `step(1/60)` and drives the controls through `Input.bot` and the edge flags (`Input.useHit`, `jumpHit`), and writes screenshots to `test/out/` (gitignored). Look at them for visual changes. `?seed` isn't used; the levels are fixed.

## Conventions

- American English everywhere, in both this repository and Tyrell: comments, docs, in-game text, identifiers, function names and save keys (favor, color, behavior, gray, center, neighbor, organize, meter). Comments and in-game text are plain English. Match the surrounding density.
- Commits go to `main` with short sentence-case subjects. Every push to `main` deploys to GitHub Pages once the checks pass.
